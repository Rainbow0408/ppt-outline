# ppt-outline

把一篇学术论文做成**可以直接拿去组会汇报的中文 PPT**的 Claude skill。

先出中文逻辑骨架和逐页大纲给你确认，确认后生成 `.pptx`。规则来自导师对多次论文汇报的真实反馈，反复迭代而成。

## 它和"让 AI 总结一下论文做个 PPT"有什么不同

- **整份 PPT 是一条问题链**：先设计逻辑再做单页，每一页都要回答"为什么接着讲这个"，最后回到开头的问题。
- **论文有图就用图**：先盘点论文的全部图表，每张图都有去处；实验装置照片、结构图、曲线直接上屏，并用中文标注指着讲。
- **每页三句话各管一件事**：标题只说这一页讲什么；标题下方的承接句说明为什么接着讲它；看完图，图下方再给结论。页面从上往下就是讲的顺序，汇报人不用犹豫先讲哪里。
- **每页信息少**：一页只讲一件事，文字合计 1–3 条；同一话题可以连续占几页。
- **数字都有交代**：图上的每个数字都贴着它的名称、单位和条件，不会孤零零出现。
- **术语就地解释**：论文自己的概念在第一次出现处用括号解释，不放单独的术语框；领域常识不啰嗦。
- **三道独立审稿**：
  1. **听众审稿**：一个没读过论文的子代理只看上屏文字，找看不懂、太口语、逻辑跳跃、数字突兀的地方；
  2. **对照论文核对**：另一个子代理拿着原文逐句核对数字和条件有没有走样；
  3. **看图审稿**：生成 PPT 后，再由没看过大纲的子代理只看渲染图，检查箭头指没指准、轴读不读得懂、有没有乱码。
  每条审稿意见要么修，要么写出"审稿人看错了"这类事实理由；同一个问题被提出两次就必须改页面。
- **页面干净**：不放附注小字、不做局限页、结尾不放讨论题。这些内容写进大纲的"可能追问"清单，供你自己准备。

## 安装

**Claude（claude.ai / 桌面端）**：把 `ppt-outline` 文件夹打包成 zip，在 Claude 的技能（Skills）设置里上传。

**Claude Code**：

```bash
git clone https://github.com/Rainbow0408/ppt-outline.git
mkdir -p ~/.claude/skills
cp -r ppt-outline/ppt-outline ~/.claude/skills/
```

需要能运行代码、读 PDF、生成 `.pptx` 的环境（Claude 的代码执行 / 文件创建功能）。三道审稿依赖子代理；没有子代理时会退化为自查，并在交付时说明。

## 使用

上传论文 PDF，然后说：

```
/ppt-outline 把这篇论文做成组会汇报 PPT
```

默认设定：中文、20 分钟、听众是本领域的老师和同学。可以直接在要求里改，例如"15 分钟""这次加一页局限"。汇报人姓名在第一次用时会问你。

想跳过确认直接出 PPT，就说"直接出 PPT"，审稿步骤不会省略。

## 适用范围

- 适合：单篇论文的组会汇报、文献分享、paper reading；优化已经做好的论文汇报 PPT。
- 不适合：多篇论文综述、单纯摘要或翻译。
- 规则最初基于网络安全方向的论文打磨，附带一节安全论文专用检查；其他领域的实测见上方示例。
